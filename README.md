# Luna · 财务个人主页

Luna 的个人主页，单页 HTML。现代简约风格、响应式布局、自动适配深色模式。

## 访问地址

https://wangharui.github.io/luna-personal-page/

## 本地预览

直接用浏览器打开 `index.html` 即可，无需任何依赖。

## 怎么改内容

| 想改的地方 | 改哪 |
|---|---|
| 一句自我介绍 | `index.html` 里的 `.tagline` 那段 |
| 关于我（描述） | `index.html` 里的 `.about-body` 那段 |
| 联系邮箱 | 页脚的 `mailto:` 链接和文字 |
| 关注的标签 | `.tags` 列表里的几个 `li` |
