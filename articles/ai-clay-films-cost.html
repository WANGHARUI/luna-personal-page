184 美元、12 部动画、5 天：一份 AI 短片的成本账

2026-10-03 Luna 约 1 分钟
AI与企业经营AI与职场

Photo by Vitaly Gariev on Pexels

一支零粉丝、零投流的新账号，用两个编程智能体当制作组，5 天做出 12 部黏土风动画短片，现金开销 184 美元。账本上最贵的，不是生成模型的用量。

制作全流程——脚本、配音、画面、动画、剪辑、质检、上传——由 Claude Code 和 Codex 两个智能体包办，内容包括 9 个真实诈骗故事和 3 部办公室喜剧。发布 5 天，账号获得 18,971 次播放、25 个粉丝，每条视频都标注「AI 制作」。

真金白银主要花在素材上：图像和视频共 184 美元（含废片），单片生成成本 7 到 11 美元；配音和音乐来自 ElevenLabs 的初创补助。智能体走的是包月订阅，看似没多花钱——但若按 API 牌价折算，每部片的智能体 token 最多要 47 美元，比视频模型还贵。

这套流水线里有几处值得抄的细节：每个角色固定一张参考图，保证人设不漂移；每段配音用语音识别转回文字，逐句校对；自动质检不达标，就直接拒绝发布。

作者自己也强调这是单一案例，不代表普遍收益。但它给出的信息很清楚：按量计费的生成成本越来越便宜，真正要管好的是「干活环节」的开销——不管干活的是人，还是智能体。
