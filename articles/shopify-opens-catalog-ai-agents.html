Shopify 开放 10 亿商品目录：任何 AI agent 都能替你下单了

2026-10-14 Luna 约 2 分钟
AI与企业经营

Photo by Nataliya Vaitkevich on Pexels

Shopify 宣布向所有 AI agent 开放代购：上个月这还是逐家谈的合作，现在任何 agent 接上就能用。

流程已经完整跑通。购物者把自己的 AI agent 连到 Shopify 旗下的 Shop 账号——那是官方用来整合订单、跟踪包裹、推荐商品的应用——agent 就能在超过 10 亿条商品信息里代逛代买，在对话中用一键 Shop Pay 结账，订单回流到 Shop 应用。安全阀也留了：每一单都要买家确认，还可以预先给 agent 立规矩，比如设置预算上限、只看发货快的商品。Shopify 给这套东西的定位，是「私人采购」。

两个细节值得注意。其一，这 10 亿条商品不限于 Shopify 店铺，还包括平台外的商品——入口的野心明显不止于自家货架。其二，门槛变了：上个月 Shopify 才宣布与 Meta 的 Muse agent 合作，那时接入还需要专门的集成；这一次，「指定合作方」的限制被整个撤掉，任何 agent 不经合作即可使用。从「挑伙伴」到「开门户」，电商平台的 agent 入口之争换了打法。

The Verge 观察到，电商已经成为 AI 竞技场——各家演示 agent 能力时，收尾动作几乎都是替人完成一笔交易：买衣服、订机票、点外卖。Google 和 Amazon 都在投入 AI 购物工具；Amazon 则站在另一边，正与 Perplexity 以及 Meta 的 Muse 缠斗，主张 agent 无权替顾客购物。Shopify 这次公开选了相反的一边：与其拦截，不如把结账环节握在自己手里。

对商家来说，这等于多了一个不用装修的门面：商品目录接进 agent，就多了一条不靠货架、不靠广告位的销路；相应地，优化的对象也可能要开始从「搜索排名」转向「agent 能不能读懂你的商品」。对行业来说，竞争的焦点正从流量入口移向结账入口——AI 代购的那最后一笔支付，在谁的体系里完成，谁就站在了新的门口。
